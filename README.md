# Make Credit Tree 🌳

> 「なりたい職業」から逆算し、確実な卒業・進級をサポートする大学生のための履修＆成績管理システム

## 📝 概要 (Overview)
Make Credit Tree は、将来のキャリア目標や設定した目標GPAに基づいて、最適な履修計画の作成を支援するアプリケーションです。
時間割の作成だけでなく、複雑な進級・卒業要件の自動チェック、学期中の出席・課題の進捗管理、さらには「あと1回休むと単位を落とす」といった危険水域アラートまで、学生生活のあらゆるリスクを視覚的に管理し、モチベーションの維持をサポートします。

## ✨ 主な機能 (Features)

* **🎯 キャリア目標＆GPA設定**
  * 11種類の職業から将来の目標を選択し、それに応じた推奨科目をハイライト。
  * 研究室配属や就活を見据えた「目標GPA」を設定し、必要な成績（S/A/B等）を逆算。
* **📅 履修計画＆時間割バリデーション**
  * 選んだ科目を直感的なタイムテーブルに配置。曜日・時限の重複を自動チェック。
  * 「3年次進級要件（61単位/GPA1.2以上）」「共通科目要件（54単位以上）」などの複雑な条件を自動判定し、不足区分をアラート。
* **📊 進捗可視化＆危険水域アラート**
  * シラバスの成績評価割合（テスト、レポート、出席点など）に基づき、現在の獲得見込み点数をプログレスバーで可視化。
  * 「あと〇回の欠席で不可確定」など、致命的なリスクが近づいた際のデッドラインアラート機能。
* **🔄 キャリア変更シミュレーション**
  * 途中で目標とする職業が変わった場合でも、取得済み単位の活かし方や軌道修正のための推奨科目を再計算。

## 🛠️ 技術スタック (Tech Stack)
本プロジェクトは、外部APIやフロントエンド専用言語を極力使用せず、**Javaのみ**でリッチな体験を実現する構成を採用しています。

* **言語・フレームワーク:** Java (Spring Boot)
* **UIフレームワーク:** Vaadin (HTML/JSを書かずにJavaコードのみでUIを構築)
* **データベース:** MySQL, PostgreSQL, または H2 Database (ローカル開発用)
